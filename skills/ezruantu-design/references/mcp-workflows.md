# EZ软图 MCP 工作流

工具名在客户端中可能带前缀；按当前服务实际暴露的名称调用。参数传 JSON 对象，不把整个对象编码成字符串。MCP 服务本身不读取业务源码、不内置模型。

## 发现项目与获取规则

`inspect_project({})` 发现工作目录里的项目文件夹和图表概要。确定项目后使用 `inspect_project({"path":"会议室预约系统"})`。

返回内容包括图表路径、名称、类型、版本、校验问题和 `png_available`。`types_not_present` 仅表示当前没有某种图，不代表用户必须生成它。

新建图种前获取 `get_diagram_schema({})`，再按需取 `list_templates({"type":"usecase"})` 等模板。使用 `validate_diagram({"diagram": ...})` 校验完整模型。`render_diagram` 返回 SVG 和布局数据，不保存文件。

如果只发现旧的聚合项目 JSON，可由用户明确需要时使用 `open_project` 读取；日常文件夹式工作不要用 `save_project` 覆盖整个项目。

## 新建与保存

1. 在确定的工作目录内调用 `create_folder({"name":"会议室预约系统"})`。新子目录使用 `parent` 指定已经存在的父目录。不重复创建已发现的目录。
2. 根据源码/需求组织当前 Schema 支持的完整图表对象，校验后调用 `save_diagram`，例如 `path` 为 `会议室预约系统/预约用例图.json`。
3. 新文件省略 `revision`；已有文件先读再改。所有路径相对工作目录，可以含子目录，不能访问 `..`、绝对路径或内部保留目录。

`save_diagram` 返回实际路径、新版本、校验结果，更新时还返回旧稿备份路径。目标已存在却未提供版本时会拒绝更新，不换用其他写入工具强行覆盖。

## 局部修改

先调用：

```json
{"path":"会议室预约系统/预约用例图.json"}
```

用于 `read_diagram`。确认返回图表的数组索引和实际 ID 后，再调用 `patch_diagram`。下例的 `revision` 和 `value` 中的 ID 必须替换成刚读到的值，示例不是固定下标的通用改名脚本：

```json
{
  "path":"会议室预约系统/预约用例图.json",
  "revision":"read_diagram 返回的 revision",
  "operations":[
    {"op":"test","path":"/model/actors/0/id","value":"employee"},
    {"op":"replace","path":"/model/actors/0/name","value":"预约人"}
  ]
}
```

支持 `add`、`replace`、`remove`、`test`。数组追加使用 `/-`，插入使用实际索引；JSON Pointer 中 `~` 写成 `~0`，`/` 写成 `~1`。删除实体、用例或参与者时，把受影响的关系修改放在同一组操作中，保证最终模型引用有效。

服务对整组操作完成后的模型统一校验，成功才保存。版本冲突时重新读取；不要沿用旧索引或忽略别人新增的内容。小修改不应替换整套项目，不应生成新的重复图来回避明确的原图修改请求。

## 导出范围与格式

导出整个项目文件夹：

```json
{
  "path":"会议室预约系统",
  "format":"svg",
  "outputs":["folder","zip"]
}
```

只导出指定图表：

```json
{
  "paths":["会议室预约系统/预约用例图.json"],
  "format":"png"
}
```

这些参数用于 `export_project`：

| 参数 | 行为 |
| --- | --- |
| `path` | 一个项目文件夹，递归包含子目录；空值或省略表示整个工作目录，只有用户确实要求全部项目时才用这个范围 |
| `paths` | 明确的图表路径数组；不能同时提供非空 `path` |
| `format` | 当前支持 `png`、`svg`、`drawio`、`json`，一次调用一种格式 |
| `outputs` | 实际多图时支持 `folder`、`zip` 或两者；省略默认文件夹，显式空数组无效；实际单图总是输出一个文件 |

格式选择来自当前用户要求；这里的 JSON 示例不是默认导出组合。如果用户要求多种格式，可分别调用并返回每种结果。

PNG 需要本机安装可用的 Edge/Chrome，查看 `png_available`。不可用时说明依赖和可选的 SVG；用户明确要求 PNG 时不要悄悄换格式。服务会隐藏渲染窗口，不需要启动桌面编辑器。

结果保存到工作目录 `.ezbitu/exports`，返回绝对路径。每张图独立生成文件，批量保持子目录；同名导出自动加序号。该目录与修改备份均不会重新进入图表源文件扫描。

批量导出遇到无效图表时会标明文件名。只修复当前任务明确允许处理的内容，不能为了让导出通过而删除问题图。用户仅要求导出时，应报告受阻文件并给出可执行的下一步。

## 文件交接与交付

MCP 修改的是磁盘上的已保存图表。它读取不到桌面画布中尚未保存的编辑，不声称已经同步这些内容；遇到需要以未保存编辑为准的任务，先让用户保存，或使用用户明确提供的数据。

返回实际输出路径，区分已保存的可编辑 JSON 与导出的图片/矢量文件。桌面端可刷新并打开源图，无需实时同步。旧稿位于服务返回的 `backup_path`；不自动清理备份或改动其他项目文件。
